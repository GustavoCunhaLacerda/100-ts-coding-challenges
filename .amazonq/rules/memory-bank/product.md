# Product Overview — Coding Challenges

## Purpose

A structured track of 100 progressive coding challenges designed to sharpen advanced software engineering skills. Each challenge presents a working but structurally flawed codebase — the goal is to identify and fix real problems with surgical precision: coupling, SOLID violations, performance bottlenecks, and poor state management.

## Value Proposition

- Learn by fixing real-world code problems, not toy examples
- Progressive difficulty from Easy to Expert
- Covers both Backend (TypeScript/Node) and Frontend (React/TypeScript)
- Each challenge is self-contained with its own dependencies and clear evaluation criteria

## Key Features

- 100 challenges across 4 difficulty tiers (Easy, Medium, Hard, Expert)
- Dual-track: Backend (algorithms, patterns, architecture) and Frontend (React, state, performance)
- `scaffold.js` CLI tool to install dependencies for any challenge: `node scaffold.js <1-100>`
- Each challenge folder contains a `CHALLENGE.md` with the full problem statement and evaluation criteria
- Solutions go in files with `.solution` suffix or a `solution/` subfolder — never modify `CHALLENGE.md`

## Target Users

- Mid-to-senior developers looking to solidify Clean Code, SOLID, and Design Patterns knowledge
- Engineers preparing for technical interviews or architecture discussions
- Developers wanting structured practice on React performance, hooks, and component design

## Challenge Distribution

|--------|--------|-------------|-------------|--------------|
